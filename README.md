# Features-Bedrock
This is the Features-Bedrock add-on for Bedrock Minecraft system.

My development is saved in a private repository. My files here are to present this addon to the public. You can find the MCAddon in the releases when one comes. If there are no changes to this repository for a while, it does not mean development has ceased; My actual development goes on in a private repository

This pack stops development at Alpha. It might contain bugs, errors or unintended visuals. If you would like to correct errors from the source code within the MCAddon, you can open a pull request to ```development-reference``` branch
# Prequisites

You also need to enable Beta APIs for some features. If you don't, some features, like the Ore Regeneration module, will not be available. All modules required with the Beta APIs can be seen in the /scripts folder.

If you are on the Bedrock Console Editions, like Xbox, PlayStation or Nintendo Switch, you will require a Bedrock Server to run.

If you are on Minecraft Education Edition, you will require something to enable Experiments. You can use resource packs or other cheats/hacks to do so.
